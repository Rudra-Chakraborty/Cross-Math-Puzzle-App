# Math Cross

A mobile maths crossword-style puzzle game developed using **Kotlin** and **Jetpack Compose** as part of a Mobile Application Development assessment.

## Features

* Randomly generated maths crossword puzzles
* Addition, subtraction, multiplication and division
* Interactive answer input
* Automatic answer validation
* Score tracking
* Optional 60-second timer
* Visual feedback for correct and incorrect answers
* Responsive Android interface

## Technologies

* **Kotlin**
* **Android**
* **Jetpack Compose**
* **Material 3**
* **Android Studio**

## How to Run

1. Open the project in **Android Studio**.
2. Allow Gradle to synchronise.
3. Start an Android emulator or connect an Android device.
4. Run the application.
